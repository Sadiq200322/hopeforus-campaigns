# HopeForUs

Community fundraising platform (GoFundMe-inspired).

## Live site
Open **index.html** via GitHub Pages after enabling it in Settings → Pages (source: main branch / root).

Or open any HTML file locally.

## Features
- Mobile-friendly responsive UI
- Campaign pages with progress circles
- Share → copy link to clipboard
- Donate modal (KickBot only after Donate)
- Signup / Login (localStorage demo)
- Dashboard & create campaign

## Pages
- index.html – Home
- marilynn-mee.html, johns-surgery.html, team-beta.html, maria-fund.html – Campaigns
- signup.html, login.html, dashboard.html, create-campaign.html
